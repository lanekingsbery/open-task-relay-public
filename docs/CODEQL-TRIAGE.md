# CodeQL baseline review

Reviewed 2026-10-03 UTC against public main `8bf8234acca6645ba824fd15b57a327643ae6ce6` and matching authoritative private source. Line numbers below identify the original scan; comments and fixes can move them.

All 30 initial findings were individually classified: 28 High and 2 Medium. Three High findings affect shipped code; 25 High findings are test assertions/extraction. Both Medium findings concern one optional local preview error response. No deployed production vulnerability was confirmed by this review. This is a scoped source/dataflow review, not a claim that the project has no vulnerabilities.

The local preview binds to 127.0.0.1, uses synthetic D1 data, denies outbound traffic, and does not use production credentials. Its raw exception response still needed a fix: browser-sniffable markup and exception details are unnecessary even on loopback. The transport now returns a fixed plain-text 500 response with `X-Content-Type-Options: nosniff` and `Cache-Control: no-store`. Tests inject malicious exception text over a real loopback HTTP request and check both the failure response and successful response forwarding.

Production excerpt heuristics are explicitly **not HTML sanitizers**. Their output can retain malformed markup and model instructions; it remains untrusted JSON/model data. RequestCard and ResolutionCard render text and JSON through React escaping, never `innerHTML` or `dangerouslySetInnerHTML`. RequestCard link attributes are escaped and executable schemes are rejected before rendering. Hostile input/source/assessment rendering regressions support these conclusions. Source-reading host allowlists, redirect denial, byte limits, schema validation and owner/action controls remain in force. Model output remains fallible; escaping does not establish factual correctness or defeat every prompt-injection strategy.

Each false-positive decision below is specific to the current sink and reachability. Reconsider it if a future change renders extracted text as HTML, executes it, changes link scheme handling, or moves fixture code into production. No paths, rules or queries were suppressed. Evidence is recorded per alert rather than a blanket dismissal.
